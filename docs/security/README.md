# authgate 서비스 보안 문서

## 개요

이 디렉토리는 authgate 서비스가 코드, 설정, DB 스키마, 테스트로 직접 적용할
수 있는 보안 설계와 증거를 추적한다.

조직 운영 절차, 인증 심사, 내부 감사, 상시 보안 운영 체계 전체는 이 디렉토리의
범위가 아니다. 이 범위 결정은
[ADR-002](../adr/002-service-security-reference.md)를 따른다.

## 문서 목록

| # | 문서 | 목적 |
|---|------|------|
| 000 | [서비스 보안 설계 기준](000-security-baseline.md) | SOC 2, ISMS-P, 개인정보 보호법령 및 안전성 확보조치 기준 중 서비스에 직접 적용할 보안 기준 |
| 001 | [서비스 감사로그 및 증거 설계](001-audit-evidence-matrix.md) | authgate가 직접 생성하는 audit event, metadata, endpoint evidence 설계 |

## 우선순위

기존 보안 기준과 충돌이 있으면 [서비스 보안 설계 기준](000-security-baseline.md)을
우선한다. 특히 개인정보의 안전성 확보조치 기준은 2025-10-31 시행
개인정보보호위원회고시 제2025-9호를 기준으로 본다.
